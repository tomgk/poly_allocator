Detailed Description

template<bool StoreTypeInfo = false>
class ArenaAllocator< StoreTypeInfo >::Iterator

Forward iterator for traversing alive allocations in the arena.

The iterator automatically skips dead allocations and provides access to allocation metadata. Iterators become invalid if the arena is reallocated during iteration.
